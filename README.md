# Продажи ЖК «Москва-Берег»

Интерактивный график продаж квартир за март–сентябрь 2026 года.

- По горизонтали — цена за квадратный метр, по вертикали — этаж.
- Цвет от красного к чёрному показывает площадь.
- Круг, ромб, треугольник и квадрат — 1, 2, 3 и 4 комнаты.
- Полная заливка — квартира продана, половинная — не продана.
- Фильтры по корпусу и легенде, подсказки и масштабирование выделением области.

Весь код и данные находятся в `index.html`. Внешние библиотеки и сборка не нужны.

Адрес после публикации: https://EricNiseRose.github.io/visual_cu/
